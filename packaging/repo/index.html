HodeiShield CLI packages

APT and DNF repositories for hodeishield, the read-only command-line client for HodeiShield, for x86_64 and arm64.

How to add them, the repository configuration and the fingerprint of the signing key are in the README of the CLI repository. Check the key you download from this site against the fingerprint stated there. This page states none of its own, because whoever can change the files on this site could change it too.

Release notes, other platforms and how to verify each release are in the same repository.
