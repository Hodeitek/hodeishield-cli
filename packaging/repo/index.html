HodeiShield CLI packages

APT and DNF repositories for hodeishield, the read-only command-line client for HodeiShield, for x86_64 and arm64.

The repositories are signed with this key; check its fingerprint before trusting it:

@FINGERPRINT@

Debian, Ubuntu

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://packages.hodeishield.com/gpg.key -o hodeishield.asc
gpg --show-keys --with-fingerprint hodeishield.asc     # compare the fingerprint with the one above
sudo install -m 0644 hodeishield.asc /etc/apt/keyrings/hodeishield.asc && rm hodeishield.asc
echo "deb [signed-by=/etc/apt/keyrings/hodeishield.asc] https://packages.hodeishield.com/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/hodeishield.list
sudo apt update && sudo apt install hodeishield

Fedora, RHEL, Rocky Linux, AlmaLinux

# DNF 5 (Fedora 41 and later)
sudo dnf config-manager addrepo --from-repofile=https://packages.hodeishield.com/rpm/hodeishield.repo
# DNF 4 (RHEL, Rocky Linux, AlmaLinux 8 and 9; needs dnf-plugins-core)
sudo dnf config-manager --add-repo https://packages.hodeishield.com/rpm/hodeishield.repo
# or, with either version
sudo curl -fsSLo /etc/yum.repos.d/hodeishield.repo https://packages.hodeishield.com/rpm/hodeishield.repo

sudo dnf install hodeishield     # dnf shows the key's fingerprint before importing it: compare it with the one above

Updates and key renewal

Updates arrive with your system's normal upgrades. The signing key is extended before it expires and keeps the same fingerprint; refresh your copy before the old expiry date, or when your system reports an expired key (clients that hold the old copy reject signatures made after it):

# Debian, Ubuntu
curl -fsSL https://packages.hodeishield.com/gpg.key -o hodeishield.asc
gpg --show-keys --with-fingerprint hodeishield.asc     # compare the fingerprint with the one above
sudo install -m 0644 hodeishield.asc /etc/apt/keyrings/hodeishield.asc && rm hodeishield.asc

# Fedora, RHEL, Rocky Linux, AlmaLinux: remove the old key first, since rpm keeps the old copy otherwise
sudo rpm -e $(rpm -q gpg-pubkey --qf '%{NAME}-%{VERSION}-%{RELEASE} %{PACKAGER}\n' | awk '/HodeiShield Packages </ { print $1 }') && sudo rpm --import https://packages.hodeishield.com/gpg.key

Release notes, other platforms and how to verify each release are in the CLI repository.
